# Security policy

BDXPAY is an experimental, non-custodial prototype. Do not use it with real
funds. Please do not publish exploitable vulnerability details in public
issues. Report suspected security problems privately to the repository
maintainer using GitHub's private vulnerability reporting feature, if enabled,
or another maintainer-approved private channel. Include reproduction steps,
impact, and relevant environment details. Do not include seed phrases,
private keys, or other secrets.
